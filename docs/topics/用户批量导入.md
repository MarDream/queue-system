# 用户批量导入

> 本文档是当前“用户批量导入”专题主文档。
> 请先阅读 [完整需求文档](../完整需求文档.md) 以了解整体范围、状态定义与文档结构。

## 1. 功能目标

为管理后台提供基于 Excel 的批量导入能力，降低用户初始建档成本，支持权限控制、数据校验、自动生成密码与整批回滚。

## 2. 适用角色

| 角色 | 权限 |
| --- | --- |
| SUPER_ADMIN | 可导入所有区域、所有允许角色 |
| REGION_ADMIN | 仅可导入其管理范围内用户，且不能导入 `REGION_ADMIN` |
| 其他角色 | 不显示批量导入功能 |

## 3. 操作流程

1. 进入「管理后台」→「用户管理」
2. 点击“批量导入模板”下载 `user_import_template.xlsx`
3. 在“用户导入模板”工作表填写数据
4. 点击“批量导入”上传 Excel 文件
5. 确认导入
6. 查看导入结果与自动生成密码
7. 刷新列表并验证登录

## 4. 模板字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 用户名 | 是 | 唯一，不超过 50 字 |
| 姓名 | 是 | 不超过 50 字 |
| 邮箱 | 否 | 如填写必须唯一 |
| 角色 | 是 | `SUPER_ADMIN` / `REGION_ADMIN` / `WINDOW_OPERATOR` |
| 区域ID | 是 | 必须存在于系统中 |
| 区域代码 | 否 | 留空自动填充 |
| 初始密码 | 否 | 留空自动生成，至少 6 位 |
| 状态 | 否 | 待激活 / 已激活 / 已禁用 |

### 填写示例

| 用户名 | 姓名 | 邮箱 | 角色 | 区域ID | 区域代码 | 初始密码 | 状态 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| operator01 | 操作员1 | op01@example.com | WINDOW_OPERATOR | 1 |  |  | 已激活 |
| operator02 | 操作员2 | op02@example.com | WINDOW_OPERATOR | 1 |  | Pass@123 | 已激活 |
| admin01 | 区域管理员1 | admin01@example.com | REGION_ADMIN | 1 |  | Admin@123 | 已激活 |

## 5. 处理规则

### 5.1 数据校验

- 用户名必填且唯一
- 姓名必填
- 角色必填且必须为允许值
- 区域 ID 必填且必须存在
- 邮箱如填写则必须唯一
- 密码如填写则至少 6 位
- 状态如填写则必须为允许值
- 批次内重复数据需拦截

### 5.2 权限控制

- 超级管理员可导入所有区域、所有允许角色
- 区域管理员只能导入其管理区域及子区域用户
- 区域管理员不能导入 `REGION_ADMIN`

### 5.3 导入结果

- 任意一行失败则整批回滚
- 错误信息需精确到行号与原因
- 自动生成密码仅在导入成功后展示一次
- 导入成功后刷新用户列表

## 6. API

### 下载模板

```http
GET /api/v1/admin/users/import/template
```

返回：Excel 文件流 `user_import_template.xlsx`

### 批量导入

```http
POST /api/v1/admin/users/import
Content-Type: multipart/form-data
```

参数：`file`

响应示例：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "importedCount": 3,
    "details": [
      {
        "username": "zhangsan",
        "generatedPassword": "Abc123xyz"
      }
    ]
  }
}
```

## 9. 常见错误

| 场景 | 错误示例 | 处理方式 |
| --- | --- | --- |
| 用户名重复 | `第 2 行用户名已存在: admin` | 修改为唯一用户名 |
| 邮箱重复 | `第 3 行邮箱已存在: test@example.com` | 修改邮箱或留空 |
| 区域ID不存在 | `第 4 行区域ID不存在: 999` | 使用正确区域ID |
| 密码过短 | `第 5 行密码至少6位` | 改为至少 6 位或留空 |
| 无权限区域 | `第 6 行无权限导入该区域的用户` | 使用授权区域 |
| 角色越权 | `第 X 行区域管理员不能导入 REGION_ADMIN 角色` | 改为允许角色 |
| 文件格式错误 | `只能上传 Excel 文件（.xlsx 或 .xls）` | 上传正确文件 |

## 12. 注意事项

- 建议单次导入不超过 1000 条
- 大批量数据建议分批导入
- 自动生成密码只展示一次，需及时保存
- 导入失败不会部分生效
- 建议导入后立即做一次登录验证
